Concesionaria de prueba página de ejemplo · no es un sitio real

Cotizá tu seguro

El cotizador de abajo está embebido igual que en el sitio de una agencia.

Esta página tiene que estar servida por http

Abierta desde el disco (file://) el cotizador no puede cargar: el navegador no manda Referer, que es lo que prueba desde qué sitio se está embebiendo, y sin eso no se emite el pase.

En desarrollo: npm run dev y abrir http://localhost:5180/prueba-embebido-9f4c2a.html.
En producción: la misma ruta sobre el dominio del cotizador.

Si acá arriba dice «Cotizador no disponible», falta el origen de esta página en SITIOS_EMBEBIBLES. El motivo exacto queda en el log del BFF, como [pase] ….
